# cuidar-portal - Portal

Portal - 7 tiles, login, subscription check - SaaS portal, links to 5 template apps.

- Same GUI as other templates, beige + green
- 7 tiles: Reporte Diario, Dashboard, Reporte Medico, Pagos, Inventario, Gastos, Gastos Admin
- Login with Supabase Auth in Fase 3
- Config via placeholders
- Points to Cuidar SaaS project only
- Never commit service_role key, real data, or personal names
